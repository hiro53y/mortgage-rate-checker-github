# 住宅ローン金利チェッカー

## 概要

現在借りている住宅ローン条件を保存し、金利変更シナリオ、主要銀行比較、借換えメリットをスマホ中心のUIで確認するWebアプリです。

## 目的

- 現在の住宅ローン条件を初回だけ保存する
- もみじ銀行の新規向け下限金利を交渉材料として比較する
- 金利変更シナリオごとの返済額増減を概算表示する
- 主要銀行との比較表と借換えメリットを概算表示する
- 銀行データと設定をJSONで保存・復元できるようにする

## 完成条件

- React + Vite + TypeScript + Tailwind CSSで実装されている
- `npm run build` が成功する
- 主要計算ロジックにテストがある
- Cloudflare Pagesで静的公開できる
- `deliverables/mortgage-rate-checker/` に自己完結パッケージが作成されている

## Cloudflare Pagesへのデプロイ手順

1. Cloudflare Pagesで新規プロジェクトを作成する
2. ビルドコマンドに `npm run build` を指定する
3. ビルド出力ディレクトリに `dist` を指定する
4. Pages Functionsを有効にする
5. KV namespaceを作成し、Pagesと金利取得Workerの両方へバインディング名 `RATE_CACHE` で紐づける
6. [金利取得Worker手順](docs/rate-worker.md)に従い、毎日06:00 JSTのCron Workerをデプロイする
7. デプロイ後、表示、JSON保存・復元、銀行比較表の取得元・適用年月・条件適合金利を確認する

## 金利自動取得と手入力補正

- 毎日06:00 JSTに独立Cloudflare Workerが銀行単位で取得し、`GET /api/rates` はKVキャッシュだけを返します。
- 住信SBIネット銀行、PayPay銀行、SBI新生銀行は公式JSON/APIを銀行別アダプタで解析します。1銀行の失敗で全体を失敗させません。
- 比較表は「条件適合金利」を主値、「広告下限金利」を参考値として分けて表示します。
- 条件適合判定には生年月日、概算物件価値、残高、残期間、団信区分を使います。旧保存データで追加項目が未入力の場合は「条件不足」になります。
- 借換え推薦は、当月の公式アダプタ値か、公式URL・確認日・適用年月を登録した手入力値だけを対象にします。
- 前月値、汎用HTML診断値、価格.com等の総合サイト値、未確認手入力値は表示できますが推薦には使いません。
- 広島銀行は公式HTMLに金利表がないため、ダイヤモンド不動産の最新月表を参考表示し、公式確認済み手入力になるまで推薦しません。
- 価格.comはShift_JISを復号して参考値に使用します。モゲチェックは銀行別の静的金利がないため数値フォールバックに使用しません。
- 比較表と借換えメリットは、選択中シナリオではなく保存済みの現在条件を基準に概算計算します。
- 現在適用金利だけを変更し、毎月返済額・ボーナス返済額が旧値のままに見える場合は警告を表示します。銀行通知額が確定している場合は、マイローン設定で返済額を手入力してください。
- 「再判定」ボタンを押すと、月返済、実質メリット、借換えメリットを現在条件基準で概算再計算します。

## PWAインストール

本アプリはWeb App ManifestとService Workerを含むPWA対応です。Cloudflare PagesなどHTTPS環境で公開すると、Android Chromeでは条件を満たしたタイミングでインストールできます。

反映後にスマホで確認する場合は、ブラウザ側の古いキャッシュやService Workerが残ることがあります。更新後に再読み込みしてから、Chromeのメニューまたは画面上部の「インストール」ボタンを確認してください。

## 今後の拡張方針

- 公式API・静的HTMLアダプタで取得不能な銀行だけBrowser Renderingを追加する
- 銀行別アダプタの実ページfixtureを拡充する
- 強整合な重複実行制御が必要になった場合はKVロックをDurable Objectへ移行する

## 注意

本アプリは金融アドバイスではなく、概算シミュレーションです。実際の条件は各金融機関の公式ページで確認してください。
