# 住宅ローン金利チェッカー

## 概要

現在借りている住宅ローン条件を保存し、金利変更シナリオ、主要銀行比較、借換えメリットをスマホ中心のUIで確認するWebアプリです。

## v10（2026/06/26）の主な変更

- 比較表の他行行から「算定不可」表示を完全廃止。3層フォールバック（公式条件適合 → aggregator参考値 → 広告下限+団信0.3%推定 → 業界中央レンジ推定）で必ず金利と返済額を表示します。
- 各行の条件適合金利には信頼度ラベル（条件適合 / 参考値 / 推定値（団信込）/ 推定値（中央レンジ））を併記します。
- 推定値（第2・3・4優先）は表示のみとし、借換え自動推薦は引き続き「当月公式値 / 公式確認済み手入力」に限定します。

## 目的

- 現在の住宅ローン条件を初回だけ保存する
- もみじ銀行の新規向け下限金利を交渉材料として比較する
- 金利変更シナリオごとの返済額増減を概算表示する
- 主要銀行との比較表と借換えメリットを概算表示する
- 銀行データと設定をJSONで保存・復元できるようにする

## Cloudflare Pagesへのデプロイ手順

1. Cloudflare Pagesで新規プロジェクトを作成する
2. ビルドコマンドに `npm run build` を指定する
3. ビルド出力ディレクトリに `dist` を指定する
4. Pages Functionsを有効にする
5. 定期取得する場合はKV namespaceを作成し、Pagesと金利取得Workerの両方へバインディング名 `RATE_CACHE` で紐づける
6. [金利取得Worker手順](docs/rate-worker.md)に従い、毎日06:00 JSTのCron Workerをデプロイする。KV未設定でもPages APIはその場で取得を実行する
7. デプロイ後、表示、JSON保存・復元、銀行比較表の取得元・適用年月・条件適合金利を確認する

## 金利自動取得と手入力補正（2026年06月25日 v9）

- 取得失敗の段階フォールバックを5系統に拡張：モゲチェック銀行別記事、ZUU online 月次まとめ、Wayback Machine の当月スナップショット、KV履歴の前月値、Cloudflare Browser Rendering（`BROWSER` バインディングがある場合のみCron内で実行）。
- 前月履歴があれば「前月値（参考）」として比較表に表示。取得失敗時のUI行は淡色化し、当月の公式値手入力導線をその場で強調する。前月値・Wayback値・Browser Rendering値は表示のみで、借換え推薦には引き続き当月公式値または公式確認済み手入力だけを使う。
- Cron Worker側のKV保存は当月成功分に限る。stale結果で当月履歴を上書きしない設計。
- 画面ビルド表示 `2026/06/25 v9` / Service Worker `mortgage-rate-checker-v9-20260625`。

## 金利自動取得と手入力補正（2026年06月24日 v8）

- KV/Cron設定済みの場合は毎日06:00 JSTに独立Cloudflare Workerが銀行単位で取得し、`GET /api/rates` は保存済み結果を返します。KVが未設定または空の場合は、その場で全銀行を取得して表示不能を回避します。
- 住信SBIネット銀行、PayPay銀行、SBI新生銀行は公式JSON/APIを銀行別アダプタで解析します。1銀行の失敗で全体を失敗させません。
- 公式構造化データがない銀行は、価格.comの借換えランキング、価格.comの銀行別借換えページ、ダイヤモンド不動産の当月銀行別表を構造解析します。近い値が複数情報源で確認できた場合だけ「複数情報源で一致」と表示します。
- 403など再試行しても改善しない応答は即時打ち切り、応答遅延は銀行内並列取得とタイムアウトで制限します。
- 比較表は「条件適合金利」を主値、「広告下限金利」を参考値として分けて表示します。
- 比較表には取得元、照合元、適用年月、照合状態を表示します。単一情報源だけの値は「要確認」として区別します。
- 条件適合判定には生年月日、概算物件価値、残高、残期間、団信区分を使います。旧保存データで追加項目が未入力の場合は「条件不足」になります。
- 借換え推薦は、当月の公式アダプタ値か、公式URL・確認日・適用年月を登録した手入力値だけを対象にします。
- 前月値、汎用HTML診断値、価格.com等の総合サイト値、未確認手入力値は表示できますが推薦には使いません。
- 広島銀行は公式HTMLに金利表がないため、ダイヤモンド不動産の最新月表を参考表示し、公式確認済み手入力になるまで推薦しません。
- 価格.comはShift_JISを復号し、ランキングカードまたは銀行別の借換え変動商品だけを構造抽出します。モゲチェックは銀行別の静的金利がないため数値フォールバックに使用しません。
- 比較表と借換えメリットは、選択中シナリオではなく保存済みの現在条件を基準に概算計算します。
- 現在適用金利だけを変更し、毎月返済額・ボーナス返済額が旧値のままに見える場合は警告を表示します。銀行通知額が確定している場合は、マイローン設定で返済額を手入力してください。
- 「再判定」ボタンを押すと、月返済、実質メリット、借換えメリットを現在条件基準で概算再計算します。

## PWAインストール

本アプリはWeb App ManifestとService Workerを含むPWA対応です。Cloudflare PagesなどHTTPS環境で公開すると、Android Chromeでは条件を満たしたタイミングでインストールできます。

反映後にスマホで確認する場合は、ブラウザ側の古いキャッシュやService Workerが残ることがあります。更新後に再読み込みしてから、Chromeのメニューまたは画面上部の「インストール」ボタンを確認してください。

## 今後の拡張方針

- 公式API・静的HTMLアダプタで取得不能な銀行だけBrowser Renderingを追加する
- 銀行別アダプタの実ページfixtureを拡充する
- 強整合な重複実行制御が必要になった場合はKVロックをDurable Objectへ移行する

## 注意

本アプリは金融アドバイスではなく、概算シミュレーションです。実際の条件は各金融機関の公式ページで確認してください。
