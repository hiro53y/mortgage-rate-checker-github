# 住宅ローン金利チェッカー

## 概要

現在借りている住宅ローン条件を保存し、金利変更シナリオ、主要銀行比較、借換えメリットをスマホ中心のUIで確認するWebアプリです。

## 目的

- 現在の住宅ローン条件を初回だけ保存する
- もみじ銀行の新規向け下限金利を交渉材料として比較する
- 金利変更シナリオごとの返済額増減を概算表示する
- 主要銀行との比較表と借換えメリットを概算表示する
- 銀行データと設定をJSONで保存・復元できるようにする

## 完成条件

- React + Vite + TypeScript + Tailwind CSSで実装されている
- `npm run build` が成功する
- 主要計算ロジックにテストがある
- Cloudflare Pagesで静的公開できる
- `deliverables/mortgage-rate-checker/` に自己完結パッケージが作成されている

## Cloudflare Pagesへのデプロイ手順

1. Cloudflare Pagesで新規プロジェクトを作成する
2. ビルドコマンドに `npm run build` を指定する
3. ビルド出力ディレクトリに `dist` を指定する
4. Pages Functionsを有効にする
5. 月次取得結果を全端末で共有する場合は、KV namespaceを作成し、バインディング名 `RATE_CACHE` で紐づける
6. デプロイ後、表示、JSON保存・復元、銀行比較表の「再取得」を確認する

## 金利自動取得と手入力補正

- 銀行比較表を毎月10日以降に開き、当月未チェックの場合は `/api/rates` で公式ページから金利候補を自動取得します。
- 自動取得値は誤取得の可能性があるため、公式確認ボタンと手入力補正を併用します。
- 判定の優先順位は `手入力補正値 > 自動取得値 > サンプル値` です。
- 借換え候補の自動選定は、最新金利を自動取得できた銀行だけを対象にし、その中で判定使用金利が最も低い銀行を選びます。未取得・取得失敗・サンプル値だけの銀行は候補にしません。
- 金利取得APIは複数URLと公式ページ内リンクを確認しますが、公式HTMLが動的表示のプレースホルダーだけを返す場合は取得失敗として扱います。
- 比較表と借換えメリットは、選択中シナリオではなく保存済みの現在条件を基準に概算計算します。
- 現在適用金利だけを変更し、毎月返済額・ボーナス返済額が旧値のままに見える場合は警告を表示します。銀行通知額が確定している場合は、マイローン設定で返済額を手入力してください。
- 「再判定」ボタンを押すと、月返済、実質メリット、借換えメリットを現在条件基準で概算再計算します。

## PWAインストール

本アプリはWeb App ManifestとService Workerを含むPWA対応です。Cloudflare PagesなどHTTPS環境で公開すると、Android Chromeでは条件を満たしたタイミングでインストールできます。

反映後にスマホで確認する場合は、ブラウザ側の古いキャッシュやService Workerが残ることがあります。更新後に再読み込みしてから、Chromeのメニューまたは画面上部の「インストール」ボタンを確認してください。
