# 住宅ローン金利チェッカー v1 仕様

## 前提

- 時点: 2026年05月06日
- 対象: スマホ向けWebアプリ
- 公開先: Cloudflare Pages
- 技術: React / Vite / TypeScript / Tailwind CSS / localStorage
- 本アプリは金融アドバイスではなく概算シミュレーションとして扱う

## 実装対象

- 初回設定保存
- ホーム画面
- 金利変更シナリオ画面
- 銀行比較表
- 借換えメリット計算
- 設定・データ管理
- サンプル銀行データ
- 公式ページを開くボタン
- JSONエクスポート / インポート

## 実装しないもの

- 銀行公式ページの自動スクレイピング
- Cloudflare Workers
- Cron
- プッシュ通知
- ログイン
- 家族共有
- AI診断

## 主要判定

- 現在適用金利: 0.755%
- もみじ銀行の新規向け下限金利: 0.950%
- 差: -0.195%
- 表示文: 現在の適用金利は新規向け下限金利より低いため、現時点では金利引き下げ交渉の優先度は高くありません。通知後に再確認してください。

## 2026年06月07日 改善仕様

- 銀行比較表と借換えメリットは、選択中シナリオではなく保存済みの現在条件を基準にする
- 現在適用金利を変更した場合、比較表の基準行、実質メリット、借換え候補は現在条件から再計算する
- 毎月返済額・ボーナス返済額は銀行通知額の手入力を正とし、自動再計算で上書きしない
- 現在適用金利から逆算した概算返済額と登録済み返済額の差が大きい場合は、ホーム、比較表、借換え画面に警告を表示する
- 借換え画面は比較表の非基準行から実質メリット最大の候補を自動表示し、候補銀行名、使用金利、現在条件の月返済額を表示する
- 公式確認未了、保障条件要確認、自動取得値の確認事項がある候補は警告付きで表示する
- 試算画面の見出しと説明文は、現在適用金利がもみじ銀行下限金利を上回る、同水準、下回る場合で分岐する

## UI方針

- スマホ幅を最優先し、PCでは中央にスマホ幅で表示する
- 白基調、濃い青をアクセントカラーにする
- 角丸カード、薄い影、大きい数値表示を使う
- 全画面で概算シミュレーションの注意文を表示する
