# 住宅ローン金利チェッカー v1 仕様

> 以下のv1記載は初期仕様の履歴です。外部取得、Cloudflare Functions/Worker、Cronの範囲は2026年06月21日以降のv7/v8仕様で置き換えられています。

## 2026年08月11日 v12 精度改善仕様

- 年月・日付判定は `Asia/Tokyo` に統一し、JST当月だけを推薦鮮度の基準にする。24時間・30時間などの時間TTLは導入しない。
- 自動推薦は、JST当月、公式由来、`verified`、利用者条件適合の自動取得値に限定する。stale、aggregator、review、推定値は表示のみとする。
- 公式確認済み手入力は、正の有限金利、有効な確認日時、JST当月の適用年月、HTTPS、対象銀行の登録済み公式host一致をすべて満たす場合だけ推薦できる。
- 条件を満たさない保存済み手入力は削除せず、`conditional` と具体的な理由、「公式確認済み手入力（参考）」を表示して計算用参考値として保持する。
- 旧保存データに適用年月がなければ入力欄を空欄で表示し、当月へ自動補完しない。新規入力だけJST当月を初期値にする。
- `rates:latest` はJST当月かつ取得日時が有効で未来でない場合だけfreshとする。stale時は通常GETでもライブ再取得し、失敗時は旧証跡を保った全行stale応答へ戻す。
- 銀行別の正常値は `rates:verified-latest:{bankId}` と `rates:verified-history:{YYYY-MM}:{bankId}` に保存する。当月・公式・`verified`・正の有限金利・正常日時を満たす値だけを書き込み、適格な旧KVだけを新キーへ移行する。
- `RateFetchResponse` の `cacheState` は `fresh | stale`、`staleReason` は `month-mismatch | invalid-fetched-at | future-fetched-at` とする。
- API `schemaVersion` は12。Cloudflare本番KV作成、実ID設定、Pages binding、Worker/Pagesデプロイは第1段階の対象外とする。

## 前提

- 時点: 2026年05月06日
- 対象: スマホ向けWebアプリ
- 公開先: Cloudflare Pages
- 技術: React / Vite / TypeScript / Tailwind CSS / localStorage
- 本アプリは金融アドバイスではなく概算シミュレーションとして扱う

## 実装対象

- 初回設定保存
- ホーム画面
- 金利変更シナリオ画面
- 銀行比較表
- 借換えメリット計算
- 設定・データ管理
- サンプル銀行データ
- 公式ページを開くボタン
- JSONエクスポート / インポート

## 実装しないもの

- 銀行公式ページの自動スクレイピング
- Cloudflare Workers
- Cron
- プッシュ通知
- ログイン
- 家族共有
- AI診断

## 主要判定

- 現在適用金利: 0.755%
- もみじ銀行の新規向け下限金利: 0.950%
- 差: -0.195%
- 表示文: 現在の適用金利は新規向け下限金利より低いため、現時点では金利引き下げ交渉の優先度は高くありません。通知後に再確認してください。

## 2026年06月07日 改善仕様

- 銀行比較表と借換えメリットは、選択中シナリオではなく保存済みの現在条件を基準にする
- 現在適用金利を変更した場合、比較表の基準行、実質メリット、借換え候補は現在条件から再計算する
- 毎月返済額・ボーナス返済額は銀行通知額の手入力を正とし、自動再計算で上書きしない
- 現在適用金利から逆算した概算返済額と登録済み返済額の差が大きい場合は、ホーム、比較表、借換え画面に警告を表示する
- 借換え画面は比較表の非基準行から実質メリット最大の候補を自動表示し、候補銀行名、使用金利、現在条件の月返済額を表示する
- 公式確認未了、保障条件要確認、自動取得値の確認事項がある候補は警告付きで表示する
- 試算画面の見出しと説明文は、現在適用金利がもみじ銀行下限金利を上回る、同水準、下回る場合で分岐する

## 2026年06月24日 v8 金利取得仕様

- 住信SBIネット銀行、PayPay銀行、SBI新生銀行は公式JSON/APIから当月の借換え変動金利を取得する
- その他の銀行は公式HTMLを診断しつつ、価格.com借換えランキング、価格.com銀行別借換えページ、ダイヤモンド不動産の当月銀行別表から構造抽出する
- 複数情報源の値が年0.150ポイント以内なら `corroborated`、単一情報源なら `review` とする
- 口コミ、手数料、団信上乗せ、固定金利、過去月、新規専用商品は借換え変動金利として採用しない
- 比較画面に取得元、照合元、適用年月、信頼状態を表示する
- 総合サイト値は比較用参考値として表示するが、自動推薦には使わない。自動推薦は当月の公式構造化値または公式確認済み手入力に限定する
- 1銀行の失敗で全体を失敗させず、銀行内取得も並列化する。非一時的な4xxは再試行せず、応答待ち時間を制限する
- KVキャッシュが存在すればGETで返し、KV未設定または空ならライブ取得へフォールバックする

## UI方針

- スマホ幅を最優先し、PCでは中央にスマホ幅で表示する
- 白基調、濃い青をアクセントカラーにする
- 角丸カード、薄い影、大きい数値表示を使う
- 全画面で概算シミュレーションの注意文を表示する
